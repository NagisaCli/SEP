## Language & System Compatibility Rule (Mandatory)

> **User Directive**:
> 怎么弄着弄着成中文版了，以后只有和我的对话是中文，项目本身内容全英文，为了系统兼容；

### Guidelines:
1. **User Communication (与用户对话)**:
   - All conversational responses, explanations, and discussions in chat with the USER must be in **Chinese (中文)**.

2. **Project Content & Codebase (项目本身内容全英文)**:
   - **User Interface (UI)**: All GUI components (WinForms, WPF, Qt, HTML, CLI) including window titles, buttons, labels, tooltips, menus, context menus, and status bars must strictly use **English**.
   - **Dialogs & Messages**: All message boxes, input prompts, warnings, error dialogs, confirmations, and toast notifications must strictly use **English**.
   - **Code, Comments & Logs**: All source code, docstrings, comments, log output, and exception messages must strictly use **English**.
   - **PML, Schemas & Configs**: All AVEVA PML files, AutoCAD commands, XML/JSON manifests, and configuration files must strictly use **English**.
